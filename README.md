# ✋ Gesture App — распознавание жестов рук в реальном времени

Десктопное приложение на Python для распознавания жестов рук с двумя режимами:

1. 🎮 **Игра "Камень-Ножницы-Бумага"** против ИИ
2. 🖱 **Виртуальная мышь** — управление курсором жестами

Всё работает **локально**, **бесплатно**, **офлайн**. Никаких платных API, облаков и регистрации. Только open-source библиотеки.

## 🚀 Возможности

- 🎥 Захват видео с камеры в реальном времени (25–30 FPS).
- 🤚 Отслеживание 21 точки руки через **MediaPipe Hands**.
- 🧠 Локальный классификатор жестов на **scikit-learn** (MLP).
- 🎮 Игра **«Камень-Ножницы-Бумага»** против ИИ с ведением счёта.
- 🖱 Управление курсором мыши жестами (движение, клики, drag).
- ⚙️ Настройки: выбор камеры, тема (тёмная/светлая), чувствительность, сглаживание.
- 💾 Сохранение настроек в `settings.json`.
- 🔒 Полностью офлайн, без платных API и облаков.
- 🎨 Современный минималистичный интерфейс на `customtkinter`.

## ⚙️ Установка

### Требования

- **Python 3.10 – 3.12** (на 3.13 возможны проблемы с MediaPipe)
- Работающая веб-камера

### Шаги

```bash
# 1. Клонировать репозиторий
git clone https://github.com/your-username/gesture_app.git
cd gesture_app

# 2. Создать виртуальное окружение (рекомендуется)
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt
```

### Системные зависимости на Linux

```bash
sudo apt install python3-tk libgl1 libglib2.0-0
```

На macOS и Windows дополнительные системные библиотеки обычно не нужны.

## 🏁 Пошаговый запуск

### 1. Сбор данных

```bash
python data_collector.py
```

**Управление:**

| Клавиша | Действие |
|---------|----------|
| `0`..`6` | Выбрать жест для записи |
| `SPACE` | Записать 100 кадров landmarks |
| `Q` | Выход |

**Рекомендации:**

- Повторите запись для каждого жеста **несколько раз** (разные руки, освещение, ракурсы).
- Минимум **300–500 примеров на класс** для стабильной работы.
- Держите руку в центре кадра, не слишком далеко и не слишком близко.

Данные сохраняются в `data/gestures.csv` (63 признака + метка класса).

### 2. Обучение модели

```bash
python train.py
```

Скрипт:

- читает `data/gestures.csv`;
- делит данные на train/test (80/20, стратифицированно);
- обучает `MLPClassifier` (скрытые слои 128 и 64, ReLU, Adam);
- выводит `accuracy`, `confusion matrix`, `classification report`;
- сохраняет модель в `models/gesture_model.pkl`.

Пример вывода:

```
Accuracy на тесте: 0.9783
Confusion matrix:
[[120   1   0 ...]
 [  2 118   0 ...]
 ...]
```

### 3. Запуск приложения

```bash
python main.py
```

Откроется главное окно с выбором режима.

## 🎮 Использование

### Режим "Игра КНБ"

1. Нажмите **«Начать раунд»**.
2. Идёт отсчёт **3 – 2 – 1 – ПОКАЗЫВАЙ!**
3. Покажите один из жестов КНБ: ✊ ✌ ✋
4. Приложение фиксирует жест игрока (0.5 сек) и выбирает жест ИИ.
5. Отображается результат: **Победа!** / **Ничья** / **Проигрыш**.
6. Счёт обновляется автоматически в верхней панели.
7. Кнопка **«Завершить игру»** возвращает в главное меню.

### Режим "Виртуальная мышь"

| Жест | Действие |
|------|----------|
| ☝ Указательный палец вверх | Движение курсора |
| 🤏 Щипок (большой + указательный) | Левый клик |
| ✌ Два пальца вверх | Правый клик |
| ✊ Кулак | Захват / перетаскивание (drag) |
| ✋ Открытая ладонь | Пауза (курсор не двигается) |

**Технические детали:**

- Кончик указательного пальца (landmark #8) маппится на экран.
- Зона отслеживания — прямоугольник 20%..80% по X и Y.
- Сглаживание движения — экспоненциальное скользящее среднее (EMA).
- Левый клик срабатывает только если щипок удерживается **0.3 сек**.
- Задержка между кликами — **0.5 сек**.

### Настройки

Открываются по кнопке **⚙ Настройки** в верхней панели:

- **Камера** — выпадающий список доступных индексов.
- **Тема** — тёмная (по умолчанию) или светлая.
- **Чувствительность курсора** — слайдер 1..10.
- **Сглаживание движения** — слайдер 0..10.
- **Сохранить** — применяет настройки и сохраняет в `settings.json`.
- **Назад** — возврат в главное меню без сохранения.

```bash

pyinstaller --noconfirm --windowed --name GestureApp ^
```

## 🐛 Возможные проблемы

### Камера не найдена

- Убедитесь, что камера не занята другим приложением (Zoom, Skype, OBS).
- Проверьте индекс камеры в настройках.
- На Windows попробуйте запустить от имени администратора.

### MediaPipe не устанавливается

- Обновите pip: `python -m pip install --upgrade pip`.
- Используйте Python 3.10–3.12, на 3.13 могут быть проблемы.
- На Linux установите `libgl1` и `libglib2.0-0`.

### Приложение работает медленно

- Уменьшите разрешение камеры (по умолчанию 640×480).
- Убедитесь, что `model_complexity=0` в `camera.py`.
- Закройте другие приложения, использующие камеру или CPU.

### Ошибки на Linux

```bash
sudo apt install python3-tk libgl1 libglib2.0-0
```

### Курсор "дёргается"

- Увеличьте сглаживание в настройках.
- Уменьшите чувствительность курсора.

### Клики срабатывают случайно

- Увеличьте время удержания щипка в `virtual_mouse.py` (`PINCH_HOLD_SEC`).
- Убедитесь, что рука хорошо освещена.
