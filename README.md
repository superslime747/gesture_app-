# ✋ Gesture App — распознавание жестов, лиц и эмоций в реальном времени

Десктопное приложение на Python с тремя режимами:

1. 🎮 **Игра "Камень-Ножницы-Бумага"** против ИИ
2. 🖱 **Виртуальная мышь** — управление курсором жестами
3. 😀 **Лицо и эмоции** — распознавание людей и их эмоций через веб-камеру

Всё работает **локально**, **бесплатно**, **офлайн**. Никаких платных API, облаков и регистрации. Только open-source библиотеки.

## 🚀 Возможности

- 🎥 Захват видео с камеры в реальном времени (25–35 FPS).
- 🤚 Отслеживание 21 точки руки через **MediaPipe Hands**.
- 🧠 Локальный классификатор жестов на **scikit-learn** (MLP).
- 🎮 Игра **«Камень-Ножницы-Бумага»** против ИИ с ведением счёта.
- 🖱 Управление курсором мыши жестами:
  - движение
  - левый клик (жест **OK**)
  - правый клик (два пальца)
  - drag (кулак)
  - пауза (открытая ладонь)
  - **скролл вверх/вниз** (большой палец)
- 😀 **Распознавание лиц и эмоций** через **DeepFace**:
  - идентификация человека по фотографиям из базы
  - определение **7 эмоций**: злость, отвращение, страх, радость, грусть, удивление, нейтрально
  - неизвестные лица показываются как **«Какой-то чел»**
- ⚙️ Настройки: выбор камеры, тема (тёмная/светлая), чувствительность, сглаживание.
- 💾 Сохранение настроек в `settings.json`.
- 🔒 Полностью офлайн, без платных API и облаков.
- 🎨 Современный минималистичный интерфейс на `customtkinter`.
- ⚡ Оптимизация: MediaPipe получает уменьшенный кадр, интерполяция курсора, адаптивное сглаживание, асинхронный анализ лиц.

## 🎮 Режимы

### 1. Игра "Камень-Ножницы-Бумага"

Играете против ИИ, показывая жесты рукой. Приложение распознаёт ваш жест, ИИ выбирает случайный, определяется победитель. Счёт ведётся автоматически.

Логика раунда:
1. Нажимаете **«Начать раунд»**.
2. Идёт отсчёт **3 – 2 – 1 – ПОКАЗЫВАЙ!**
3. Показываете ✊ ✌ ✋ — жест фиксируется 0.5 сек.
4. ИИ выбирает свой жест.
5. Результат: **Победа!** / **Ничья** / **Проигрыш**.
6. Счёт обновляется: `Игрок X : Y ИИ`.

Правила:
- ✊ Камень побеждает ✌ Ножницы
- ✌ Ножницы побеждают ✋ Бумагу
- ✋ Бумага побеждает ✊ Камень

### 2. Виртуальная мышь

Управление курсором через жесты. Работает как обычная мышь — двигайте рукой, кликайте, скроллите.

Технические детали:
- Кончик указательного пальца (landmark #8) маппится на экран.
- Зона отслеживания — прямоугольник **20%..80%** по X и Y.
- **Сглаживание** — экспоненциальное скользящее среднее (EMA) с адаптацией по FPS.
- **Интерполяция** — большие прыжки курсора делятся на микрошаги.
- **Левый клик** (OK) срабатывает при удержании жеста 0.25 сек.
- **Задержка между кликами** — 0.5 сек.
- **Скролл** разгоняется от 12 до 60 «щелчков»/сек за 0.8 сек удержания.
- Скролл на Windows выполняется через **SendInput** (надёжнее `pyautogui.scroll`).

### 3. Лицо и эмоции

Распознавание людей по фотографиям и определение их эмоций в реальном времени.

Что показывается:
- **Имя** человека (если лицо есть в базе).
- **«Какой-то чел»** (если лицо неизвестно).
- **Эмоция** с эмодзи: 😄 Радость, 😢 Грусть, 😠 Злость, 😨 Страх, 😲 Удивление, 🤢 Отвращение, 😐 Нейтрально.
- **Рамка** вокруг лица с подписью.

Как добавить человека:
- Через **приложение** — введите имя справа, нажмите «📸 Сохранить лицо».
- Через **сборщик** — клавиша **F**, введите имя в окне.
- Вручную — положите фотографии в `data/faces/<имя>/*.jpg` и нажмите «🔄 Пересобрать базу из фото».

Для точного распознавания рекомендуется **3–5 фотографий** человека с разных ракурсов и при разном освещении.

| Метка | Жест | Описание |
|-------|------|----------|
| 0 | ✊ Камень | Кулак |
| 1 | ✌ Ножницы | Два пальца (указательный + средний) |
| 2 | ✋ Бумага | Открытая ладонь |
| 3 | ☝ Указательный | Указательный палец вверх |
| 4 | 🤏 Щипок | Большой + указательный соединены (не используется в мыши) |
| 5 | 👍 Большой палец | Большой палец вверх |
| 6 | 👌 OK | Большой + указательный образуют кольцо |

### Действия в виртуальной мыши

| Жест | Действие |
|------|----------|
| ☝ Указательный палец вверх | Движение курсора |
| 👌 OK | **Левый клик** (удерживать 0.25 сек) |
| ✌ Два пальца вверх | Правый клик |
| ✊ Кулак | Захват / перетаскивание (drag) |
| ✋ Открытая ладонь | Пауза (курсор не двигается) |
| 👍 Большой палец **выше** указательного основания | **Скролл вверх** |
| 👍 Большой палец **ниже** указательного основания | **Скролл вниз** |

## 😀 Распознавание лиц

### Эмоции

DeepFace определяет **7 эмоций**:

| Эмоция | Русский | Эмодзи |
|--------|---------|--------|
| angry | Злость | 😠 |
| disgust | Отвращение | 🤢 |
| fear | Страх | 😨 |
| happy | Радость | 😄 |
| sad | Грусть | 😢 |
| surprise | Удивление | 😲 |
| neutral | Нейтрально | 😐 |

Точность — **60–80%** в реальных условиях. Это нормально для бесплатной модели.

### База лиц

Хранится в двух местах:
- **Фотографии**: `data/faces/<имя>/*.jpg` — исходные снимки.
- **Эмбеддинги**: `data/faces_db.pkl` — усреднённые векторы лиц для быстрой идентификации.

Идентификация — по **косинусному расстоянию** между эмбеддингами. Порог `threshold = 0.45`:
- Меньше → строже (чаще показывает «Какой-то чел»).
- Больше → либеральнее (может путать людей).

Порог настраивается в `face_recognizer.py`:

```python
def __init__(self, threshold: float = 0.45):
```

### Что НЕ попадает в git

Из соображений приватности в `.gitignore` исключены:
- `data/faces/*/` — фотографии людей.
- `data/faces_db.pkl` — эмбеддинги лиц.
- `data/gestures.csv` — данные жестов.
- `models/*.pkl` — обученные модели.
- `models/*.task` — модель MediaPipe.

## ⚙️ Настройки

Открываются по кнопке **⚙ Настройки** в верхней панели:

- **Камера** — выпадающий список доступных индексов (определяется автоматически).
- **Тема** — тёмная (по умолчанию) или светлая.
- **Чувствительность курсора** — слайдер 1..10.
- **Сглаживание движения** — слайдер 0..10.
- **Сохранить** — применяет и сохраняет в `settings.json`.
- **Назад** — возврат в главное меню без сохранения.

Настройки применяются сразу и сохраняются между запусками.

## ⚡ Производительность

- Обработка видео в отдельном потоке (`threading`) — GUI не лагает.
- Целевой FPS: **25–35**.
- Разрешение камеры: **640×480**, обработка MediaPipe — **320×240** (в 4 раза меньше пикселей).
- MediaPipe в режиме `model_complexity=0` (быстрее).
- `CAP_PROP_BUFFERSIZE = 1` — снижает лаг на 1–2 кадра.
- Плавное движение курсора: EMA-сглаживание + интерполяция.
- Скролл через `SendInput` — работает даже там, где `pyautogui.scroll` бессилен.
- **Анализ лиц** — асинхронный, раз в 0.4 сек в отдельном потоке. Видео при этом идёт 30 FPS.
- **DeepFace** при первом запуске скачивает модели (~200 MB) в `%USERPROFILE%\.deepface\` — это разовая операция, дальше всё офлайн.
