# ✋ Gesture App — распознавание жестов рук в реальном времени

Десктопное приложение на Python для распознавания жестов рук с двумя режимами:

1. 🎮 **Игра "Камень-Ножницы-Бумага"** против ИИ
2. 🖱 **Виртуальная мышь** — управление курсором жестами

Всё работает **локально**, **бесплатно**, **офлайн**. Никаких платных API, облаков и регистрации. Только open-source библиотеки.

## 🚀 Возможности

- 🎥 Захват видео с камеры в реальном времени (25–35 FPS).
- 🤚 Отслеживание 21 точки руки через **MediaPipe Hands**.
- 🧠 Локальный классификатор жестов на **scikit-learn** (MLP).
- 🎮 Игра **«Камень-Ножницы-Бумага»** против ИИ с ведением счёта.
- 🖱 Управление курсором мыши жестами:
  - движение
  - левый клик (жест **OK**)
  - правый клик (два пальца)
  - drag (кулак)
  - пауза (открытая ладонь)
  - **скролл вверх/вниз** (большой палец)
- ⚙️ Настройки: выбор камеры, тема (тёмная/светлая), чувствительность, сглаживание.
- 💾 Сохранение настроек в `settings.json`.
- 🔒 Полностью офлайн, без платных API и облаков.
- 🎨 Современный минималистичный интерфейс на `customtkinter`.
- ⚡ Оптимизация: MediaPipe получает уменьшенный кадр, интерполяция курсора, адаптивное сглаживание.

## ⚙️ Установка

### Требования

- **Python 3.10 – 3.12** (на 3.13+ возможны проблемы с MediaPipe)
- Работающая веб-камера
- **Не используйте Python 3.13/3.14** — MediaPipe там не работает

### Шаги

```bash
# 1. Клонировать репозиторий
git clone https://github.com/superslime747/gesture_app-.git
cd gesture_app-

# 2. Создать виртуальное окружение через Python 3.12
py -3.12 -m venv venv

# Windows (cmd):
venv\Scripts\activate.bat

# Windows (PowerShell):
.\venv\Scripts\Activate.ps1

# Linux/macOS:
source venv/bin/activate

# 3. Обновить pip и установить зависимости
python -m pip install --upgrade pip setuptools wheel
pip install -r requirements.txt
```

### Системные зависимости на Linux

```bash
sudo apt install python3-tk libgl1 libglib2.0-0
```

### Проверка установки

```bash
python -c "import mediapipe as mp; print('MediaPipe:', mp.__version__); print('solutions:', hasattr(mp, 'solutions'))"
```

Ожидаемый вывод:

```
MediaPipe: 0.10.21
solutions: True
```

Если `solutions: False` — установилась новая версия MediaPipe (1.x). Переустановите:

```bash
pip install mediapipe==0.10.21
```

## 🏁 Пошаговый запуск

### 1. Сбор данных

```bash
python data_collector.py
```

**Управление:**

| Клавиша | Действие |
|---------|----------|
| `0`..`6` | Выбрать жест для записи |
| `SPACE` | Записать 100 кадров landmarks |
| `Q` | Выход |

**Рекомендации:**

- Повторите запись для каждого жеста **несколько раз** (разные руки, освещение, ракурсы).
- Минимум **300–500 примеров на класс** для стабильной работы.
- Держите руку в центре кадра, не слишком далеко и не слишком близко.

Данные сохраняются в `data/gestures.csv` (63 признака + метка класса).

**Проверить, сколько данных собрано:**

```bash
python -c "import csv; rows=list(csv.reader(open('data/gestures.csv'))); print('Всего:', len(rows)-1); from collections import Counter; print(Counter(r[-1] for r in rows[1:]))"
```

### 2. Обучение модели

```bash
python train.py
```

Скрипт:

- читает `data/gestures.csv`;
- делит данные на train/test (80/20, стратифицированно);
- обучает `MLPClassifier` (скрытые слои 128 и 64, ReLU, Adam);
- выводит `accuracy`, `confusion matrix`, `classification report`;
- сохраняет модель в `models/gesture_model.pkl`.

Пример вывода:

```
Accuracy на тесте: 0.9783
Confusion matrix:
[[120   1   0 ...]
 [  2 118   0 ...]
 ...]
```

Хорошая точность — **> 0.95**.

### 3. Запуск приложения

```bash
python main.py
```

Откроется главное окно с выбором режима.

| Метка | Жест | Описание |
|-------|------|----------|
| 0 | ✊ Камень | Кулак |
| 1 | ✌ Ножницы | Два пальца (указательный + средний) |

| 3 | ☝ Указательный | Указательный палец вверх |
| 4 | 🤏 Щипок | Большой + указательный соединены (не используется) |
| 5 | 👍 Большой палец | Большой палец вверх |
| 6 | 👌 OK | Большой + указательный образуют кольцо |

## 🎮 Использование

### Режим "Игра КНБ"

1. Нажмите **«Начать раунд»**.
2. Идёт отсчёт **3 – 2 – 1 – ПОКАЗЫВАЙ!**
3. Покажите один из жестов КНБ: ✊ ✌ ✋
4. Приложение фиксирует жест игрока (0.5 сек) и выбирает жест ИИ.
5. Отображается результат: **Победа!** / **Ничья** / **Проигрыш**.
6. Счёт обновляется автоматически в верхней панели.
7. Кнопка **«Завершить игру»** возвращает в главное меню.

### Режим "Виртуальная мышь"

| Жест | Действие |
|------|----------|
| ☝ Указательный палец вверх | Движение курсора |
| 👌 OK (большой + указательный кольцом) | **Левый клик** (удерживать 0.25 сек) |
| ✌ Два пальца вверх | Правый клик |
| ✊ Кулак | Захват / перетаскивание (drag) |
| ✋ Открытая ладонь | Пауза (курсор не двигается) |
| 👍 Большой палец **выше** указательного основания | **Скролл вверх** |
| 👍 Большой палец **ниже** указательного основания | **Скролл вниз** |

**Технические детали:**

- Кончик указательного пальца (landmark #8) маппится на экран.
- Зона отслеживания — прямоугольник 20%..80% по X и Y.
- Сглаживание — экспоненциальное скользящее среднее (EMA) с адаптацией по FPS.
- Интерполяция — большие прыжки курсора делятся на несколько микрошагов.
- Левый клик (OK) срабатывает только если жест удерживается **0.25 сек**.
- Задержка между кликами — **0.5 сек**.
- Скролл разгоняется от 12 до 60 «щелчков»/сек за 0.8 сек удержания жеста.
- Скролл на Windows выполняется через `SendInput` (надёжнее, чем `pyautogui.scroll`).

## ⚙️ Настройки

Открываются по кнопке **⚙ Настройки** в верхней панели:

- **Камера** — выпадающий список доступных индексов (определяется автоматически).
- **Тема** — тёмная (по умолчанию) или светлая.
- **Чувствительность курсора** — слайдер 1..10.
- **Сглаживание движения** — слайдер 0..10.
- **Сохранить** — применяет и сохраняет в `settings.json`.
- **Назад** — возврат в главное меню без сохранения.

## 🐛 Возможные проблемы

### MediaPipe не устанавливается / нет `mp.solutions`

- Используйте **Python 3.12**. На 3.13+ MediaPipe не работает.
- Установите **строго** версию `0.10.21`:
  ```bash
  pip install mediapipe==0.10.21
  ```
- Проверьте: `python -c "import mediapipe as mp; print(hasattr(mp, 'solutions'))"` → должно быть `True`.

### Камера не найдена

- Убедитесь, что камера не занята другим приложением (Zoom, Skype, OBS, браузер).
- Попробуйте сменить индекс камеры в настройках.
- На Windows запустите от имени администратора.

### Приложение работает медленно

- Уменьшите разрешение камеры (по умолчанию 640×480).
- Убедитесь, что в `camera.py` стоит `processing_width=320` (MediaPipe получает уменьшенный кадр).
- Закройте другие приложения, использующие камеру или CPU.

### Курсор мыши дёргается

- Увеличьте **Сглаживание** в настройках.
- Уменьшите **Чувствительность** курсора.
- Проверьте FPS — при < 20 движение может ощущаться рывками.

### Скролл не работает

- Убедитесь, что активное окно — то, которое вы хотите скроллить (не окно Gesture App).
- Проверьте тест:
  ```bash
  python -c "import time; from virtual_mouse import _scroll_windows; time.sleep(3); [_scroll_windows(-1) for _ in range(20)]"
  ```
  Откройте блокнот, кликните по нему, дождитесь скролла.
- Если не работает — запустите cmd от имени администратора (антивирус может блокировать SendInput).

### Клики срабатывают случайно

- Увеличьте `CLICK_HOLD_SEC` в `virtual_mouse.py` до `0.35`.
- Убедитесь, что рука хорошо освещена.

### Ошибки на Linux

```bash
sudo apt install python3-tk libgl1 libglib2.0-0
```

## ⚡ Производительность

- Обработка видео в отдельном потоке (`threading`) — GUI не лагает.
- Целевой FPS: **25–35**.
- Разрешение камеры: **640×480**, обработка MediaPipe — **320×240** (в 4 раза меньше пикселей).
- MediaPipe в режиме `model_complexity=0` (быстрее).
- `CAP_PROP_BUFFERSIZE = 1` — снижает лаг на 1–2 кадра.
- Плавное движение курсора: EMA-сглаживание + интерполяция.
- Скролл через `SendInput` — работает даже там, где `pyautogui.scroll` бессилен.
